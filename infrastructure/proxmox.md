# Proxmox
A virtual environment that is designed to do enterprise virtualization
### Def enterprise virtualization
Virtualization is the virtual (meaning not physically exsisting but made up by software to do so) representation of servers, storage, and networks.
Enterprise virtualization is the technologies that manage IT resources efficiently. You create virtual versions of physical resources (like servers, storage devices, networks, and even OSs). 
For example, desktop virtualization allows users to run desktop environments on virtual machines hosted. 
### Def enterprise
A business or a company
### With Proxmox
You can easily manage VMs and containers and networking. 
You can manage your infrastructure (the software that manages computing resources) --> Like servers, storage, network components, and security.
