## Database and SQL Learning Goals
1. Understand various data models used by database management systems. (SO 1, 6) 
2. Apply rules of normalization to develop a fully normalized relational data model. (SO 1,2,6) 
3. Use various database management systems to implement data models (relational, 
NewSQL, noSQL). (SO 2,6) 
4. Understand various data models and languages and which is most appropriate for given 
situations, especially with semi-structured and complex data (SO 1,2,6) 
5. Write complex data definition and data manipulation SQL queries. (SO 1,2,6) 
6. Understand multiple-user database processing issues and implementation techniques of 
database management systems (index structures, concurrency control, recovery, and query 
processing. (SO 6) 
7. Understand basic database security issues and practices to maintain database operations 
in the presence of risks and threats. (SO 1,2, 6) 
8. Analyze and implement system requirement changes. (SO 1,2,6) 
9. Understand basic enterprise and cloud-based database processing issues for large-scale 
data analysis. (SO 6)
