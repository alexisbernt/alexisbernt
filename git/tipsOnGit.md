# Using Git

## How ro Push to GitHub from Command Prompt / Terminal
- Navigate to your project folder/directory.
- Right click then click open in terminal
- Type "git init"
- Type "git add" + filename.txt
- Type "git commit -m "first commit"
- Type "git remote add origin" + URL
- Type "git push" + URL or "git push origin master"
- Then you might change some files
- After changes: "git commit -m "My new change name"
- Type "git add"
- Type "git push origin master"
