Learning css programming.
Your file must have a .css extension to it.

To connect the css file to the html file you are going to use an element called link.
The html link code: "<link rel="stylesheet" href="style.css"> // now anything coded in the style.css file will be linked to that html file.

/* # Now for the CSS CODE: */

body { /* anything that you do in body will then impact the html file */
  height: 100%;
  width: 100%;
  background-color: green;
}
________________________________________________________

/* SELECTORS */ 
Selectors connect html to css. 
1. Create an id (ex: id="element_name") in your html code
2. Write the id
Ex:
#element_name {
  background-color: green; 
}

/* ELEMENTS and CLASSES */
  The html code: <h1 class="heading">Name of Page
  The css code: 
    h1.heading {
      color: blue;
    }

/* The "*" sign means "the universal selector" */ 
* {
  color: purple;
}

____________________________________________________
/* WORKING WITH THE BACKGROUND */
body {
  background-color: mediumslateblue; 
  opacity: 0.4
  background-image: url("url of the image . jpg") 
}

/* selecting the specific portions / sections of the HTML code to alter */
h1, p {
  color: white;
}

/* MARGINS */
p {
  margin-left: 20px; /* moving a certain amount of pixels */
  margin-left: 50%; /* moving based on width */
  margin-top: 50px;
  margin-right: 50px;
  margin-bottom: 50px;
  /* or determine all of the margins */
  margin: 50px 50px 50px 50px; /* top right bottom left */
}

b {
  margin-top: inherit;
}
