Automata = study of computational problems using abstract machines. Automata theory is a branch of the theory of computation. It deals with the study of abstract machines and their capacities for computation.

Programming = computationally telling a computer how to solve problems or carry out functionality and procedures.


DFA =
Deterministic finite automata (or DFA) are finite state machines that accept or reject strings of characters by parsing them through a sequence that is uniquely determined by each string. The term “deterministic” refers to the fact that each string, and thus each state sequence, is unique.
- States
- Transitions
