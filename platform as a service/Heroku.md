# Heroku 
A platform as a service (PaaS) that allows developers to deploy, manage, and scale apps without worrying about infrastructure. 
It’s not a tool for building apps directly but INSTEAD a platform where you can run your apps once you've built them. 
Heroku is cloud based (cloud-based means using resources like servers, storage, or software over the internet instead of on your local computer). 

### Run apps on Heroku 
For example:
You build an app using a language like Python, PHP, JavaScript, Ruby, or Java.
Then - use Heroku to host and manage it. Heroku is in charge of taking care of tasks like servers, databases, and scaling.
