# Definitionals:

### IDE 
An IDE ( known as an Integrated Development Environment) is software that combines commonly used developer tools into a compact GUI application. 
It is a combination of tools like a code editor, a code compiler, and code debugger with an integrated terminal.
### Interpreter
Interpreters are the computer program that will convert the source code or a high level language into intermediate code / machine level language.
### SDK
A software development kit (known and abreviated as an SDK) is a set of platform-specific building tools for developers. You require components like debuggers, compilers, and libraries to create code that runs on a specific platform, operating system, or programming language.
