# Python Documentation

In Python you import libraries that are essentially packages of code that can be imported into your script so that their functionality is incorporated.

In computing, a pipe is a way to send data from one program (or process) to another. It’s like a virtual tube that connects the output of one process to the input of another.

subprocess is a package that can be used in the Python programming language. It runs system-level commands, just like if you typed them into the terminal or command prompt.
