Understanding my Windows Operating System and Files 

GOG Games = Digital distribution platform for video games and films. I did not need this folder so I deleted it. 

PerfLogs = A folder used by Windows that stores log files “Performance Logs” that has information about the computer’s performance. Just ignore it (doesn’t take up too much space and if deleted will come back). 

Program Files = A folder that stores program files for 64-bit applications. This is where applications that are not part of the Operating System get conventionally installed. So the installation files for most applications (programs) get stored in Program Files. This holds the core executable files and supporting components to operate a system. 

Program Files (x86) = A folder that stores program files for 32-bit applications. These are for programs that run under the x86-32 emulator. 

Users = A folder to store all the personal data and settigs for each individual user account on the system. Each individual user can have their own documents, pictures, downloads, and more. This allows each user to have their own customized experience and keeps each user’s files seperate. 

Windows = Where Windows stores the files neccessary for the Operating System. Will store things like system applications, drivers, and settings. (Don’t touch / delete / alter this folder unless you know what you are doing). 

DumpStack = a file created by Windows to help with troubleshooting whenever Windows detects a crash. Windows dumps all the code in memory to a file. 

RECOMMENDED NOT TO DELETE: 
DLLs: “.dll” stands for dynamic link library. For Windows Operating Systems you use DLL for the functionality of the operating system. DLLs is going to help your OS and programs load quicker, take less disk space, and run faster. DLL contains code and data that can be used for code reusability that can be used by more that one program at the same time. 

When you install Visual Studio (a development application) on your system appverifUI.dll and vfcompat.dll get installed. 	

appverifUI.dII = Linked with the application verifier tool to detetc and troubleshoot issues in applications. Helps see common programming mistakes. 

vfcompat.dII = Visual studio compatibility features and makes sure that development of the environment operates smoothly with Windows or Microsoft products. Will look for compatibility issues.
